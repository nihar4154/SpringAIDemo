# SpringAIDemo

SpringAIDemo is a demo Spring Boot project showcasing integration examples and sample features.

## Contents
- Basic Spring Boot application
- Example controllers and services
- Tests and sample configurations

## Getting started
1. Ensure Java 11+ and Maven/Gradle are installed.
2. Clone the repository:
   git clone https://github.com/nihar4154/SpringAIDemo.git
3. Build and run with Maven:
   mvn clean spring-boot:run
